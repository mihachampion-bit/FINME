Мини-инструкция:
1) Локально: сохраните FINME.html и откройте в браузере.
2) GitHub Pages: переименуйте в index.html, залейте в репозиторий, включите Pages.
3) Экспорт: JSON (бэкап) или CSV (операции). Импорт: JSON.
4) localStorage обычно ~5–10MB; IndexedDB значительно больше.

Управление блоками и статьями

Блоки

• ▲/▼ меняют порядок блоков (сохраняется).
• “Скрыть” не удаляет данные. “Удалить” удаляет блок/статьи и связанные расходы.

Статьи

• “Удалить” статью удаляет связанные расходы по этой статье.
