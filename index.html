Подсказки:
• Клик/тап по сумме открывает “Детализацию”.
• Даты: самый свежий день — слева. Для больших периодов листай окно “Новее/Старее”.
• Данные хранятся локально в IndexedDB (подходит для многолетнего учёта).

Справка

• ISO-неделя начинается в понедельник.
• Сальдо = Приходы − Расходы.
• “Доли расходов” показывают top-12 категорий для читаемости.
Мини-инструкция:
1) Локально: сохраните FINME.html и откройте в браузере.
2) GitHub Pages: переименуйте в index.html, залейте в репозиторий, включите Pages.
3) Экспорт: JSON (полный бэкап) или CSV (список операций). Импорт: JSON.
4) IndexedDB: рассчитан на большие объёмы, localStorage обычно ограничен ~5–10MB.
